# Style variants

Each choice is a fixed select in the content element. Existing records with an
empty selection keep their current appearance. The four Site Settings palettes
still supply the colors; no per-element color values are needed. Compare the
editable [English](https://dev-crispframe.ppxl.dev/components/style-variants) and
[German](https://dev-crispframe.ppxl.dev/de/components/stilvarianten) examples.

| Element | Choice | Use when |
| --- | --- | --- |
| Hero | Narrow headline | A short statement should feel deliberate and prominent. |
| Hero | Standard headline | You want the established balanced layout. |
| Hero | Wide headline | A longer editorial thought needs a calmer line break. |
| Services | Cards | Offers should read as distinct choices. |
| Services | Open columns | Related services should feel like one connected overview. |
| Feature grid | Cards | Each benefit needs its own boundary. |
| Feature grid | Open columns | Icons and concise copy should lead without card surfaces. |
| Projects | Cards | A portfolio needs a quick, scannable grid. |
| Projects | Editorial rows | Case studies need more room for imagery and context. |
| Testimonials | Cards | Several customer voices should be grouped compactly. |
| Testimonials | Open quotes | Quotations should sit naturally in an article-like flow. |
| Call to action | Contained panel | A conversion moment should stand apart. |
| Call to action | Open section | The invitation should follow the page's rhythm. |

The defaults are **Standard**, **Cards**, **Cards**, **Cards**, **Cards**, and
**Contained panel**, respectively. The content, section background, image,
links, and existing Site Settings remain editable as before. Open presentations
use the same semantic markup and keyboard focus behavior as their defaults.
